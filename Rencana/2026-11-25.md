**E1**

```javascript
const hasil = kali(6, 7);
```

**E2**
```javascript

const x = sisa(17, 5);
```

**E3**
```javascript
function dua(x) { return x * 2; }
function empat(x) { return dua(dua(x)); }
const y = empat(3);
```
