## Yang salah, dan koreksinya

### Re-check 3: "ada error"

Aku menjawab "ada error karna di bagian if terdapat false".

Salah. Kondisi false bukan error. Blok if dilewati, program lanjut.

Yang benar: `&&` berhenti di `user.alamat` sebelum menyentuh `user.alamat.kota`. Tidak ada properti yang dibaca dari null, jadi tidak ada error. Justru `&&` yang mencegahnya.

Kalau `&&` dihapus:

```javascript
if (user.alamat.kota) { }    // ini baru TypeError
```

### Re-check 4: "string"

Aku menjawab "bolehMasuk isinya string".

Salah. Isinya false, tipenya boolean.

`||` mengembalikan sisi yang dipilih apa adanya. `punyaTiket` dan `punyaUndangan` dua-duanya boolean, jadi hasilnya boolean. Tidak mungkin string kalau tidak ada string di kedua sisinya.
