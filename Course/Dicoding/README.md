# Course/Dicoding

Kelas Dicoding dari program **Bangun Negeri (DBN) 2026**, dikerjakan berdampingan
dengan Backend Journey.

**Mulai:** 2026-11-24 · **Selesai:** 2027-01-22 · **Total:** 60 hari

---

## Dua kelas yang dipilih

| Kelas                                         | Jam | Modul | Tenggat |
|-----------------------------------------------|-----|-------|---------|
| Belajar Dasar Pemrograman JavaScript          | 46  | 111   | 60 hari |
| Belajar Dasar Structured Query Language (SQL) | 11  | 44    | 60 hari |

**Total 57 jam.** Kelas tidak bisa diganti setelah dipilih.

---

## Kenapa dua kelas ini

| Kelas      | Alasan                                                             |
|------------|--------------------------------------------------------------------|
| JavaScript | materi sama dengan Backend Journey minggu 1-7, tapi bersertifikat  |
| SQL        | dipakai setiap hari di backend, dan target database-nya PostgreSQL |

**Yang tidak dipilih, dan kenapa:**

| Kelas                             | Kenapa tidak                                        |
|-----------------------------------|-----------------------------------------------------|
| Cloud & Gen AI di AWS             | baru terpakai minggu 8+, dan bisa dipelajari gratis |
| Memulai Pemrograman dengan Python | jalur backend sudah Java, bukan Python              |
| Visualisasi Data                  | frontend, bukan backend                             |
| Belajar Dasar AI                  | bukan inti backend                                  |
| Prompt Engineering                | bukan inti backend                                  |

## Isi folder

| File                    | Isi                                          | Diisi kapan         |
|-------------------------|----------------------------------------------|---------------------|
| `Jadwal 60 Hari.md`     | rencana per hari                             | sekali, sudah ada   |
| `Progress.md`           | catatan harian: hari ke-, modul, lulus/tidak | **setiap hari**     |
| `Catatan JavaScript.md` | ringkasan yang belum kamu paham              | saat hari 1 dimulai |

**Aturan:** file baru hanya dibuat kalau benar-benar akan diisi. File kosong yang
menggantung dihitung sebagai utang.

## Hubungan dengan Backend Journey

| Peran               | Sumber                  |
|---------------------|-------------------------|
| Input — baca materi | Kelas Dicoding          |
| Latihan — uji paham | Gerbang Backend Journey |
| Catatan harian      | `TRAIN_LOG.md` di root  |

**Satu topik, dua bentuk.** Bukan dua kurikulum.

Kuis Dicoding itu **pilihan ganda**. Lulus kuis tidak berarti bisa menulis kode.
Karena itu gerbang Journey tetap wajib.

## Aturan main

| #   | Aturan                                                | Kenapa                       |
|-----|-------------------------------------------------------|------------------------------|
| 1   | Topik yang sudah dikuasai: lewati modulnya, kuis saja | kelas self-paced             |
| 2   | Gerbang Journey tetap wajib                           | kuis bukan menulis kode      |
| 3   | Waktu habis: Dicoding dulu, Journey belakangan        | Dicoding punya tenggat       |
| 4   | Gerbang Journey tidak absen lebih dari 2 hari         | tanpa latihan tak menempel   |
| 5   | Kuis dan ujian akhir wajib dikerjakan                 | tanpa itu tak ada sertifikat |

---

## Cara memakai setiap hari

1. Buka `Progress.md`, lihat hari terakhir yang tercatat.
2. Buka `Jadwal 60 Hari.md`, cari baris hari berikutnya.
3. Kerjakan modul Dicoding.
4. Kalau sudah dikuasai, lewati modulnya dan langsung kuis.
5. Kerjakan gerbang Journey untuk topik yang sama.
6. Catat satu baris di `Progress.md`.
7. Commit.
